Hulao Pass — Google sign-in and special-battle leaderboard
Web 0.16.0-web-special-account-leaderboard; Mac app remains 2.5
Released 2026-10-13 (America/Los_Angeles)

PLAY
https://3kingdoms.cc.cd/special/hulao/
Refresh to get the update. Google sign-in and a username are now required.
Existing campaign accounts work here. Open 英雄榜 / Leaderboard in the toolbar.

RANKING
Players with at least one win rank first, by total wins descending ONLY.
Players with no wins follow, by total losses descending.
Equal scores share a rank. Losses do not break ties between winning players.
Each completed registered match counts once; reloading an earlier save of that
same match does not create another result. Unfinished/restarted matches do not
count as losses. Public entries contain username, rank, wins and losses only.

SAVES AND RESULTS
Special saves are local to this browser and separated by signed-in account.
Completed results persist in Cloudflare D1 with the account. A failed result
submission is retained locally and retried when connected. A new ranked match
must register online before gameplay begins.
Previous anonymous saves remain available from Saves > Previous local saves
(unranked); the original slots are preserved. Imported raw backups are also
unranked. Export before changing devices. Results are cloud-backed; special
battle snapshots are not cloud saves.

SCOPE
This is a casual leaderboard: the server verifies ownership, an allowlisted
starting state, terminal-state constraints and one result per match. It does
not replay every command server-side, so it is not an authoritative anti-cheat
system. No native app, game rules, campaign save format or JEV secrets changed.
Details and limitations: docs/evidence/special-hulao-leaderboard/REPORT.txt
